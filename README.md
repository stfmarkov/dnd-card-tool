# Item Cards

A small desktop utility for **designing and printing magic item cards** for *Dungeons & Dragons 5e* home games. Fill in the fields, pick your artwork, and hand a physical card to your player when you give them the item.

---

## How to use it

### 1. Fill in the card fields

The right panel is the editor. Work through the sections from top to bottom:

| Field | What to put here |
|---|---|
| **Template** | The visual style of the card — see the templates section below |
| **Item name** | The name as it will appear on the card (e.g. *Flame Tongue*) |
| **Item type** | Pick from the dropdown or type a custom value (e.g. *Weapon, Longsword*) |
| **Rarity** | Common / Uncommon / Rare / Very Rare / Legendary / Artifact — controls the colour of the type line |
| **Artwork** | Upload an image file; it will be embedded in the card |
| **Description** | The item's rules text. Use the **+ Add effect** button to insert formatted snippets for common effect types |
| **Footer** | A small line at the bottom of the card — good for campaign name, source, or session number |

### 2. Watch the preview update live

The left panel shows an exact preview of what will print. It updates as you type.

Use the **action buttons** in the top-right corner of the preview:

| Button | What it does |
|---|---|
| ⋮ | Open the action menu |
| ► | Close the action menu |
| Export | Save the card as a PNG |
| New | Clear the editor and start a fresh card |
| Save | Save the current card so you can come back to it later |

---

## Views

Use the **menu button** (☰) in the top-left corner to switch between views:

- **Split view** — editor on the right, live preview on the left. This is the main working view.
- **Grid view** — browse and manage all your saved cards.

---

## Tips

- The **Item type** and **Rarity** fields accept free text — you can type anything that isn't in the list.
- Rarity colours on the type line match the standard D&D 5e colour coding.
- The **Two-sided** template is great for boss loot or named weapons where you want the players to pick it up and look at it.
- Save often. The **Save** button stores the card locally so you can reload it in a future session.
